## 🎯 Sobre o Projeto

O **Nike Store Concept** é um UI Concept desenvolvido para compor meu portfólio de desenvolvimento front-end.

O projeto apresenta uma experiência visual e interativa para explorar diferentes modelos de sneakers, utilizando um layout de alto impacto com produtos em destaque, tipografia oversized, mudanças dinâmicas de cores e transições personalizadas entre os modelos.

Desenvolvido com **HTML, CSS e JavaScript puro**, o conceito demonstra a criação de interfaces modernas para moda e e-commerce, explorando animações, microinterações, responsividade e manipulação dinâmica da interface.

> Este projeto é um conceito independente desenvolvido exclusivamente para fins educacionais e de portfólio. Não possui vínculo oficial com a Nike.

## ⚡ Funcionalidades

### 👟 Showcase de Sneakers

- Apresentação de diferentes modelos
- Produto em grande destaque no centro da interface
- Nome do sneaker selecionado
- Descrição e chamada para detalhes
- Navegação entre produtos
- Botões de próximo e anterior

### 🔄 Transições entre Produtos

- Animações personalizadas durante a troca dos sneakers
- Entrada e saída em direções diferentes
- Movimento baseado na direção da navegação
- Rotação durante as transições
- Alteração de escala
- Efeito de blur durante a movimentação
- Animação independente das informações do produto
- Feedback visual no texto de fundo

### 🎨 Temas Dinâmicos

Cada sneaker possui sua própria identidade visual.

Ao navegar entre os produtos, a interface altera dinamicamente:

- Cor ou gradiente do background
- Cor do texto principal
- Cor do texto NIKE ao fundo
- Contraste dos elementos
- Cores da navegação
- Ícones do header
- Botões de navegação
- Informações do produto

Isso permite que cada modelo tenha uma apresentação visual própria sem alterar a estrutura principal da página.

### 👟 Modelos Apresentados

- Nike Air Force 1
- Nike Air Max 90
- Nike SB Dunk
- Nike Air Max 97
- Nike Air Force Blue

### 🔤 Tipografia Oversized

- Texto "NIKE" em grande escala no background
- Produto posicionado sobre a tipografia
- Composição visual inspirada em campanhas de sneakers
- Alteração dinâmica da cor do texto conforme o produto
- Efeito de pulso durante as transições

### 🧭 Navegação Desktop

- Menu centralizado
- Links com estética futurista
- Efeito glassmorphism
- Bordas geométricas
- Detalhes neon em azul e roxo
- Microinterações no hover
- Indicador visual na coleção principal
- Elementos numéricos inspirados em interfaces digitais

### 📱 Menu Mobile

- Menu fullscreen exclusivo para dispositivos móveis
- Efeito de blur no background
- Navegação em formato editorial
- Numeração das categorias
- Animações de abertura e fechamento
- Botão dedicado para fechar
- Links secundários para Stories e Blog
- Indicador visual de status
- Fechamento através da tecla ESC

### 💫 Microinterações

- Logo animada
- Indicador neon pulsante
- Hover nos itens de navegação
- Animações nos ícones do header
- Setas interativas
- Mudanças de escala
- Alterações de letter-spacing
- Efeitos de glow
- Feedback visual durante a navegação

## 🎨 Destaques do Design

- **Visual Futurista** - Interface inspirada em experiências digitais de moda e sneakers
- **Tipografia de Impacto** - Nome da marca utilizado como elemento visual da composição
- **Produto como Protagonista** - Sneakers posicionados no centro da experiência
- **Temas Individuais** - Cada produto possui cores e atmosfera próprias
- **Neon Details** - Azul ciano e roxo utilizados em elementos interativos
- **Glassmorphism** - Transparência e blur aplicados à navegação
- **Geometria Assimétrica** - Botões e itens com recortes personalizados
- **Animações Direcionais** - Movimento acompanha o sentido da navegação
- **Interface Imersiva** - Experiência concentrada em uma única viewport
- **Microinterações** - Feedback visual em diferentes elementos da interface

## 📱 Responsividade

O projeto possui uma experiência específica para diferentes tamanhos de tela.

### Desktop

- Navegação horizontal completa
- Sneaker centralizado em grande destaque
- Tipografia oversized ao fundo
- Informações posicionadas na parte inferior
- Controles independentes de navegação

### Mobile

- Menu desktop substituído por navegação fullscreen
- Produto redimensionado e reposicionado
- Texto NIKE adaptado ao tamanho da viewport
- Informações reorganizadas para telas menores
- Botões de navegação reposicionados
- Interface adaptada para áreas seguras do dispositivo

### Telas Menores

- Breakpoints específicos para smartphones estreitos
- Ajustes para dispositivos com pouca altura
- Uso de `svh` e `dvh`
- Suporte a `safe-area-inset`
- Dimensionamento fluido dos elementos

## ⚙️ Sistema de Produtos

Os produtos são controlados através de JavaScript, permitindo definir individualmente:

- Imagem
- Nome
- Cor ou gradiente de fundo
- Cor dos textos
- Cor da tipografia de fundo
- Rotação do sneaker
- Escala
- Posicionamento horizontal
- Posicionamento vertical

Essa estrutura permite adicionar novos produtos mantendo o mesmo sistema de apresentação e animações.

## 💼 Sobre este Case

Este projeto faz parte da coleção de **UI Concepts** desenvolvidos para meu portfólio.

O objetivo deste case é explorar uma abordagem mais experimental para interfaces de moda e e-commerce, utilizando transições, tipografia de grande escala, temas dinâmicos e microinterações para transformar a apresentação de produtos em uma experiência visual.

O conceito pode ser expandido para uma aplicação completa utilizando React, TypeScript, Next.js, backend, banco de dados, autenticação e integração com sistemas de pagamento.
